# Car Detailing Demo — Riyadh

A concept preview of a multi-page, bilingual (Arabic RTL / English) website for a car paint-protection and detailing centre.

## Features
- 5 pages: Home, Services, About, Booking, Contact
- Dark/light theme with an animated sliding switch
- Hero video: separate animated sources for desktop and mobile
- Arabic/English toggle with full RTL support
- Booking form with split-shift time slots that opens WhatsApp with a prefilled message
- Live open/closed status based on opening hours (Asia/Riyadh)
- Self-hosted fonts and icons (Tajawal, Material Symbols)
- No frameworks, no build step

## Run locally
Open `index.html`, or run `python3 -m http.server`.
